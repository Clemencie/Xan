## Termos do motor

| Termo | O que é |
|---|---|
| **MDI** | Motor do Destino Imparcial — o nome do motor |
| **HMAC-DRBG** | gerador determinístico criptográfico do SP 800-90A §10.1.2 |
| **fonte viva** | entropia do sistema operacional (`os.urandom`) |
| **fonte semeada** | entropia reproduzível a partir de uma semente declarada |
| **amostragem por rejeição** | técnica que elimina viés de módulo |
| **compromisso** | hash da declaração gravado **antes** do dado |
| **revelação** | sal + payload gravados **depois**, para conferência |
| **diário** | arquivo JSONL append-only encadeado por SHA-256 |
| **raiz de Merkle** | hash único que resume todo o diário |
| **selo** | hash da cabeça gravado num arquivo externo |
| **Registro de Regras** | conjunto fechado de 36 modificadores possíveis |
| **fato** | valor objetivo declarado que alimenta uma regra |
| **livro de relações** | ledger de eventos entre um NPC e um alvo |
| **agenda** | relógio de segmentos que avança por rolagem |
